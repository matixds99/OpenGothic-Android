# Spis New Balance

- `SPIS_NB.xlsx` – arkusz graczy z opisem New Balance (umiejętności, nauczyciele, zbroje, bronie, gildie, ognik, osiągnięcia, **bossy** i inne).
- `bossy.csv` – zakładka „Bossy” jako zwykły tekst (nazwa lub nagłówek sekcji, gdzie go znaleźć, ilość PN), do szybkiego przeszukania.

Muzyka bossów w grze (poprawka 82 na gałęzi `touch-ui`) nie korzysta z tej listy: o tym, kto jest bossem i jaki utwór gra,
decydują skrypty NB (`RX_IsBoss`, `RX_CheckMusicBoss`, dźwięki `BATTLE_*` z `SFX.DAT`).
